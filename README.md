# Shtemarm

Would you like me to help for building an HTML code for English test website (Շտեմարան). The whole books' sections without missing anything. The website has to include the options for choosing the question book (Շտեմարան 1, 2, 3 with their book covers there I'll give you the images), the section for each question book, whether we want to take a test or just study (for some sections there aren't any options to choose you have to answer them by writing the numbers that are right or just tap the options), you have to add the explainations for the right answers and explain why my choice was wrong if it's even wrong. And for the tests it has to offer to control the quantity of questions (and multiple variants of taking tests: exam questions which include realistic exam questions taken from the question books and has to be made using real exam structures with 80 question like how it's done in Armenia, and another option to take random sections). The study has to be done gamified and not traditional (or be chosen between traditional and gamified experience for the user-friendly experience). Unlock the rest of the question books, and then finish up by fixing design issues for computers and laptops (for phones it's looking fine but fix the text layout)

I'll give you everything you need (pictures for book covers and the whole books for writing them all), what else do you need before starting?
