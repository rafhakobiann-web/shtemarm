# Ֆիզիկայի երկու բնօրինակ շտեմարանների թվայնացման ընթացք

## 2026-10-27 · Բնօրինակ PDF-ներով լուծվող 250 առաջադրանք

Երկու գրքերի **առաջին 125-ական բնօրինակ առաջադրանքները** դարձան ինտերակտիվ՝ իրենց ֆիզիկական PDF էջերի և տպագիր պատասխանների հետ համադրությամբ։ Սա **չի նշանակում 250 հարցի տեքստային արտագրում**․ հարցերը, բանաձևերն ու գծագրերը երևում են օգտատիրոջ սարքում բացված բնօրինակ PDF-ից։

- Գիրք I՝ առաջադրանքներ **1–125**, էջերի սկզբնամասերը՝ **5–32**, պատասխանների աղյուսակ՝ **406-րդ էջ**։
- Գիրք II՝ առաջադրանքներ **1–125**, էջերի սկզբնամասերը՝ **5–31**, պատասխանների աղյուսակ՝ **409-րդ էջ**։
- Երկու գրքերում միասին **250 առաջադրանքի էջ և ճիշտ տարբերակի կոդ** է գրանցվել, դրանցից **51-ը** նաև ունեն առանձին վերանայված տեքստային արտագրություններ։ Ուստի 250 թիվը չի գումարվում այդ 51-ին որպես առանձին նոր հարցերի ընդհանուր թիվ։
- Սկանների բանալիների առաջին էջերից համապատասխան **1–4 թվային կոդերը** համեմատվել են տեսանելի տպագիր աղյուսակների հետ։ Սկզբնական տեքստային բանկի բոլոր պատասխաններն ու էջերը ավտոմատ ստուգվում են նոր ցուցիչի նկատմամբ։
- Նոր ուղին՝ `/physics/scan-practice`։ Սովորողը ընտրում է 2017 թ. նույնական PDF-ը, տեսնում խնդիրը բնօրինակ էջի մեջ, նշում **1–4** տարբերակը, և ստանում պատասխան՝ աղյուսակի կոդով։ Ուսուցման և քննության ռեժիմներ, հարցերի խառնում, միջակայք, արդյունք և ընտրած հարցին վերադառնալու հնարավորություն։
- **Աղբյուրի SHA-256 ստուգումը պարտադիր է գնահատման համար։** Եթե օգտատիրոջ PDF-ը տարբեր է այդ բնօրինակից, համակարգը **չի գնահատում**՝ խուսափելով այլ հրատարակության պատասխանների սխալ կապակցումից։ PDF-ը բեռնվում է տեղական IndexedDB-ից կամ սարքի ֆայլերից, չի ուղարկվում սերվերին և չի պատճենվում GitHub։
- Էջերը նկարներ և բանաձևեր պարունակելու պատճառով **չեն հրապարակվում որպես կայքի հանրային պատճեններ**։ Ավելացվել են միայն թվային էջահղումները, տպագիր հարցի համարը և պատասխանների կոդերը։ Արդյունքում աղբյուրի իրական գծագրերն ու բազմասյուն դասավորությունը չեն փոխարինվում սխալ OCR-ով։

**Դեռ չի ավարտվել.** առաջին երկու գրքերի 125-րդ առաջադրանքից հետո ամբողջ հարցաշարի տեքստային մուտքագրումը, բոլոր բաժինների թվային բազմամաս խնդիրները, հետագա էջերի պատասխանների ստուգումը և առանձին գծագրերի տեղափոխումը։ Սկսած 126-րդ առաջադրանքից արդեն կան թվային/խառը պատասխաններ, ուստի չի կարելի դրանց նկատմամբ կիրառել «1–4 ընտրովի» ռեժիմը առանց նոր պատասխանատիպային աուդիտի։

Ստուգում՝ `bunx vitest run src/test/physics-scan-index.test.ts`, `bun run build`։ Այս փոփոխությունը չի ավելացնում պարբերական ավտոմատացում։

---


**Աղբյուրները**՝ օգտագործողի տրամադրած 2017 թ. երկու սկանավորված գրքերը՝ `fizika-1_compressed.pdf` (430 PDF էջ, առաջին առաջադրանք՝ էջ 5, պատասխաններ՝ էջ 406) և `fizika-2_compressed.pdf` (436 PDF էջ, առաջին առաջադրանք՝ էջ 5, պատասխաններ՝ էջ 409)։

Աղբյուրների ճշգրիտ SHA-256 արժեքները պահվում են `src/lib/physics-source.ts`-ում. սերվերում բնօրինակ սկանների պատճեններ **չեն հրապարակվում**։

## Կայքում ավարտված աշխատանք

- **51 իրական առաջադրանքի տեքստային առաջին փուլ**՝ առաջին գրքից 26, երկրորդից՝ 25, երկուսի «Մեխանիկա — Կինեմատիկա» թեմայից։ Պահված են `public/data/physics-original-transcribed.json`-ում, ըստ գրքի համարի, տպագիր առաջադրանքի համարի և ֆիզիկական PDF էջի։
- Յուրաքանչյուր ներմուծված հարց ունի չորս տարբերակ, բնօրինակ պատասխանների աղյուսակից ստուգված պատասխանի կոդ և կարճ ուսումնական բացատրություն։
- Ավելացվել է `/physics/original` էջը՝ ուսուցման ու քննության ռեժիմներով, պատասխանների ստուգմամբ, հաջորդ/նախորդ առաջադրանքներով, արդյունքով և տվյալ առաջադրանքի բնօրինակ PDF էջի հղումով։
- Մնացած՝ միայն OCR-ով կարդացված կամ գծագիր ու բարդ բանաձև պարունակող առաջադրանքները **դեռ չեն ներմուծվել որպես գնահատվող հարցեր**։ Նախորդ 110 *հեղինակային ուսումնական առաջադրանքները* մնում են առանձին և չեն ներկայացվում որպես բնօրինակից արտագրություններ։
- `scripts/digitize-physics-scans.py` գործիքը բուն PDF-ներից ստեղծում է OCR **ստուգման միջանկյալ JSON**, ոչ թե ավտոմատ հրապարակվող հարցաշար։ Այն ստուգում է բնօրինակների SHA-256-ը, OCR տվյալներում գրանցում էջերը, հավանական համարները, տեքստերը և խնդրահարույց տեղերը։ Բազմաթիվ սյունակներ, հավասարումներ, նկարներ և էջից էջ շարունակվող հարցերը դեռ պահանջում են մարդու համեմատություն։

## OCR-ի գործարկում

Անհրաժեշտ է Python 3, PyMuPDF և Tesseract՝ `Armenian` լեզվային տվյալներով։

```bash
pip install PyMuPDF
python scripts/digitize-physics-scans.py \
  --book1 fizika-1_compressed.pdf \
  --book2 fizika-2_compressed.pdf \
  --output physics-ocr-review --pages 5:30 --workers 2
```

Ամբողջ էջերի հերթի մշակման համար սահմանափակ միջակայքով աշխատիր՝ օրինակ `--pages 31:60`, հետո `--pages 61:90`։ Աուդիտի JSON-ների վերանայումը պարտադիր է։ Պատասխանները չպետք է ինքնաբերաբար միացվեն OCR հարցերին՝ միայն համարների նմանության հիման վրա։ Միայն էջը, պահանջը, չորս տարբերակները, անհրաժեշտ գծագիրը և բնօրինակ բանալիի համապատասխանությունը ստուգելուց հետո լրացրու `physics-original-transcribed.json`-ը։

**Ստուգել աշխատող գրքերի բանկը**՝ `bunx vitest run src/test/physics-original.test.ts` և `bun run build`։

## Բաց մնացած մասը

Առաջին մասի 2100 և երկրորդ մասի 2088 առաջադրանքների ամբողջական տեքստային ներմուծումը **ավարտված չէ**։ Մնացել է լրացնել մյուս բաժինները, բազմամաս թվային խնդիրներն ու գծագրերը և հաստատել պատասխանները։ Գրքերի երկու PDF-ներն ամբողջությամբ կարելի է կարդալ նախկինում ներդրված տեղական PDF ընթերցիչով։

Այս թարմացումը փաստացի առաջին աղբյուր-ստուգված, ինտերակտիվ առաջադրանքներն է ավելացնում՝ ոչ թե ամբողջ 866-էջանոց կորպուսի պատրաստ թվայնացումը։
